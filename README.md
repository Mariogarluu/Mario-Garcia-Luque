## 🌟 Características Principales

* 🌓 **Modo Oscuro & Claro Instantáneo:** Alternancia de temas fluida y sin lag implementada mediante variables CSS (`data-theme`) en `document.documentElement` y persistencia en `localStorage`.
* 💼 **Doble Enfoque Profesional:** Orientado tanto a contratación en plantilla por empresas como a prestación de servicios técnicos freelance.
* 📂 **Proyectos de Producción y Reales:**
  * **Meta Force (Proyecto Intermodular 2º DAM):** Plataforma integral de gestión de centros deportivos con Angular 19, Supabase (34 tablas relacionales, 100% políticas RLS), 17 Edge Functions en Deno, control de accesos físicos por QR firmado con JWT y app Android nativa en Kotlin con Jetpack Compose.
  * **Bot de Música para Discord:** Sistema de streaming de audio concurrente con Node.js, Discord.js v14 y comandos slash (marcado con aviso transparente de su ciclo de vida y estado actual de la API).
* 🎓 **Estudios Vinculados a Código:** Conexión directa entre la formación académica (CPIFP Alan Turing DAM, 42 Málaga Fundación Telefónica, I.E.S. Gerald Brenan DAW/SMR) y los repositorios reales correspondientes (`Meta_Force_Expo`, `Ft-Maincore`).
* ⚡ **Rendimiento Ultrarrápido:** Bundling optimizado con Vite, carga asíncrona de recursos, cero librerías pesadas innecesarias y arquitectura modular de componentes.
* 📱 **Diseño 100% Responsivo:** Adaptado meticulosamente para dispositivos móviles, tablets y monitores de alta resolución.

## 🚀 Puesta en Marcha en Local

### 1. Clonar el Repositorio
```bash
git clone https://github.com/Mariogarluu/Mario-Garcia-Luque.git
cd Mario-Garcia-Luque
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Iniciar Servidor de Desarrollo
```bash
npm run dev
```
La aplicación estará disponible de inmediato en `http://localhost:5173`.

### 4. Compilar para Producción
```bash
npm run build
```
Genera los archivos listos para producción en la carpeta `dist/`.

## 🌐 Despliegue en Vercel (100% Gratuito)

Este proyecto está configurado para desplegarse con cero fricción en **Vercel**:

1. Entra en [vercel.com](https://vercel.com/) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** > **"Project"**.
3. Selecciona el repositorio `Mario-Garcia-Luque`.
4. Vercel detectará automáticamente que es un proyecto **Vite**.
5. Pulsa **"Deploy"**. En menos de un minuto tu portfolio estará online con dominio SSL gratuito `.vercel.app`.
